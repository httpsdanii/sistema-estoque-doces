# 🍪 Sistema de Estoque para Loja de Doces

Meu primeiro projeto em C#! Um sisteminha simples de controle de estoque que roda no console.

## 📋 O que ele faz
- Mostra os produtos em estoque
- Adiciona novos produtos
- Aumenta quantidade de produtos
- Remove produtos ou quantidades

## 🚀 Como usar
1. Clone o repositório
2. Abra no Visual Studio
3. Aperte F5 e pronto!

## 🛠️ Feito com
- C#
- .NET
- Visual Studio 2022
